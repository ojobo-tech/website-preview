# Ojobo Agbo Eje — website

The live website is [ojoboagboeje.com](https://ojoboagboeje.com/). This repository contains its editable content and publishing workflow.

To update the site with your existing GitHub account, start with the [plain-language editing guide](EDITING.md). It links directly to the files for page text, images, articles, projects, research, speaking dates, reading-room notes, and shared header/footer wording. Saving a change to `main` starts the automatic live build.

If you prefer, ask Codex to make an edit in plain language. It can update the same files, check them, and push the result after your review.

Visitor analytics and Google search reporting are described in the [analytics section of the editing guide](EDITING.md#visitor-analytics-and-google-search-reporting).
